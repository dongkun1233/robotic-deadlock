# 물리 시간 모델 확대 학습: 사전 설계 (2026-11-03)

이 단계는 초기 가중치 재구성과 본 학습 준비다. 물리 모델·진입 규칙·변수 정의는 예비 실험과 동일하게 고정한다. 최종 테스트는 생성·실행하지 않는다.

## 자료 분리

단일·이중·다중 레이아웃마다 학습 48개 및 개발 48개를 새로 생성한다. AGV 12/24대 × 출발 창 0/15초 × 균등/진입 편중/출구 편중의 12개 조건에 네 개씩 배정한다. 기존 물리 모델 예비 자료와 공학 검증 자료의 내용 해시·시드를 대조하고 새 학습·개발 간 중복도 배제한다. 새 개발 자료는 초기값 보정에 사용하지 않는다. 개발 결과는 이후 설계 점검용이며 최종 확인 자료가 아니다.

## 초기 가중치 보정

레이아웃마다 24개 후보를 사전에 고정한다. FCFS와 기존 고정 4변수 기준, 예비 학습에서 얻은 모든 방법·모든 시드의 최선 후보(중복 제외), 새 무작위 후보로 구성한다. 예비 개발 점수에 따라 후보를 골라 넣지 않는다. 후보 출처와 전체 벡터를 manifest에 저장한다.

24개를 새 학습 48개에서 평가한다. FCFS·고정 4변수 기준을 유지하고 나머지 네 후보는 학습 목적함수 순으로 선택하되 기존 선택·두 기준 벡터와 L2 거리 0.35 이상을 요구한다. 네 개를 채울 수 없으면 목적함수 순으로 부족분을 채우고 fallback 사실을 남긴다. 양의 상수배는 순위를 바꾸지 않으므로 중복된 크기 자유도를 없애기 위해 벡터는 L2 단위 길이를 유지한다. 음수 계수도 허용한다. 이 선정 기준은 결과 확인 전에 고정한다.

FCFS는 진입 가능한 공통 후보 중 가장 먼저 기다린 AGV를 선택한다. 순수 Waiting 가중치와 FCFS의 전체 궤적 해시가 새 학습 시나리오 모두에서 같은지 확인한 뒤 해당 결과를 공유 초기 관측으로 재사용한다. 엄격 FCFS는 별도 진입 규칙 대조군으로 실행한다.

## 예산과 공정성

후속 본 학습 잠정 예산은 방법별 72회, 시드 101/202/303/404/505다. 무작위 탐색·BO·PSO는 레이아웃별로 같은 초기 여섯 후보와 같은 시나리오를 사용한다. 모든 탐색 시드에서도 초기 여섯 후보를 고정하여 탐색 과정의 무작위성을 비교한다.

초기 후보 보정 비용을 숨기지 않는다. 각 방법/시드의 전체 학습 비용은 공통 보정 24회 + 후속 탐색 72회 = 96개 단계별 호출 예산 항목으로 표시한다. 초기 여섯 개는 보정과 검색 양쪽에 기록되는 재사용 관측이므로, 한 작업에 귀속되는 고유 벡터 평가는 추가 중복이 없을 때 최대 90개다. 96을 실제 독립 계산 횟수로 해석하지 않는다. 탐색의 초기 여섯 관측은 72회 안에 포함되고, 계산은 기존 보정 결과를 재사용한다. 공통 보정이 모든 방법에 제공되므로 결과가 더 좋아져도 이를 BO·PSO 고유 개선으로 주장하지 않는다. 물리적으로 실행된 횟수와 예산상 관측 횟수를 구분한다.

24회 공통 보정은 세 레이아웃에서 72회 목적함수 평가·3,456개 에피소드다. 순수 Waiting 동등성·엄격 FCFS 검증에 288개 에피소드가 추가되어 보정 단계 전체는 3,744개다. 모두 기록하고 실패를 제외하지 않는다.

후속 검색 전체는 45개 학습 작업(3레이아웃×3방법×5시드), 목적함수 3,240회다. 보정 비용까지 각 작업에 귀속시키면 4,320회다. 초기 관측 재사용을 제외한 실제 계산 비용은 이 수보다 작다. 72회 예산과 시드 5회가 충분하다는 주장은 아직 하지 않으며 탐색 곡선·시드 변동성으로 점검한다.

## 목적함수·검증·저장

목적함수는 미완료 시나리오 수×1201 + 평균 제한 완료 시간(상한 1200초)이다. 실패를 삭제하거나 성공 실행만 평균내지 않는다. 물리 시간 간격 0.01초, 직진 속도 0.8m/s, 셀 크기 1.5m, 회전 가감속 등 기존 설정은 유지한다.

모든 결과에 시나리오 ID·내용 해시·궤적 해시·안전 assertion 통과 여부·실행시간을 기록한다. 체크포인트를 같은 파일에 원자적으로 갱신하며 flush/fsync로 저장한다. 재개할 때 설정·벡터·시나리오 순서를 검증하고, 완성되지 않은 자료를 완성 결과로 집계하지 않는다.

큰 시나리오 manifest는 gzip과 SHA256 검증값으로 저장한다. 실행 시 manifest.json이 없다면 검증 후 복원한다. 저장 위치는 기존 사용자 저장소의 research/physical-time-v1-20261102 브랜치다.

## 다음 판단

보정 결과로 초기 여섯 후보를 확정하고 본 학습을 진행한다. 이후 새 개발 자료에서 조건별 성능·시드 변동·시간 간격 민감도를 확인한다. 예비 자료에서 나온 잠정 최종 표본 수(372/216/1248)는 새 개발 분산으로 재계산한 뒤 최종 테스트 전에 확정한다. 네 변수 ablation과 진입 규칙 대조군은 별도 비교로 유지한다.


후속 개발 평가에는 학습에서 고른 초기 여섯 후보 중 최선인 warmstart_best 기준을 추가한다. 초기값 보정의 이득과 후속 검색의 이득을 구분하는 기술통계용 대조군이며, 주 비교 15개에 대한 확증 검정과 섞지 않는다. 이 대조군은 개발 평가 전에 정의하고 개발 점수로 선택하지 않는다.

비용 범위: 96회는 이번 확대 학습의 증분 예산이다. 후보 출처에 포함된 기존 예비 학습의 역사적 비용(총 486회 목적함수 관측·5,832개 예산상 학습 에피소드)은 별도 기록한다. 공통 사전학습 후보를 모든 방법에 제공하므로 내부 탐색 방법 비교는 같은 출발점이지만, 전체 시스템을 처음부터 만드는 비용을 96회만으로 표현하지 않는다. 새로운 초기화의 효율 우위를 주장하려면 역사적 비용·보정 비용까지 포함한 별도 대조 실험이 필요하다.
