# 팀원 FairBO·FairPSO 참고 실험: 사전 설계

## 출처와 실제 변경점

대상은 poketmon2004-droid/robotic-deadlock-fairness의 고정 커밋 f7240040f2b88a3a02462c3c78eb68c66a4cc9a0이다.

- analyze_step103_holdout.py의 FairBOModel은 지역 진입 대기가 20초/40초 이상이면 우선권을 준다. 여러 보호 대상 중 가장 오래 기다린 AGV를 우선한다. FairPSO도 같은 클래스로 기존 PSO 가중치를 사용한다.
- 따라서 공개 코드의 FairBO/FairPSO는 새로운 최적화기가 아니라 학습 가중치+장기 대기 우선 규칙이다. 원본 Fair 비교는 보호 없이 학습한 가중치를 그대로 사용한다.
- train_realistic_bo_pso.py의 Improved_BO/Improved_PSO는 별도로 완료시간+최대 대기 벌점으로 학습한다. 그 벌점 방식과 Fair 규칙을 혼합하지 않는다.

## 이번에 실행할 비교

현재 FCFS와의 차이가 작은 다중 교차로를 먼저 본다. 새 확대 자료의 학습 48개·개발 48개를 사용한다. 최종 테스트는 생성하지 않는다.

1. 보호 없이 무작위 탐색·BO·PSO를 학습한다.
2. 그 가중치를 그대로 두고 보호 20초·40초를 적용한다. 이것이 팀원 FairBO/FairPSO 구조에 해당하며 규칙만의 효과를 분리한다.
3. 보호를 켠 상태에서 각 방법을 다시 학습한다. 이는 팀원 원본을 확장한 재학습 비교이며 원본 Fair 구현이 재학습했다고 표현하지 않는다.

모든 학습에 동일 초기 여섯 후보, 동일 학습 시나리오, 동일 30회 예산과 시드 101을 사용한다. 세 보호 조건×세 방법의 아홉 학습 작업, 예산상 총 270회 목적함수 호출이다. 초기 여섯 관측은 30회 안에 포함한다. 이번에는 한 시드의 예비 실험이며 알고리즘 수렴·우열을 확정하지 않는다.

초기값은 이미 확대 학습 자료에서 골라둔 공통 여섯 후보다. 그 이전 보정 및 예비 학습 비용은 공유 선행 비용으로 명시하며 30회만으로 처음부터 학습했다는 뜻이 아니다. 개발 결과로 초기값·임계값을 선택하지 않는다.

## 유지하는 조건과 포팅 차이

직진 속도 0.8m/s, 셀1.5m, 각속도1rad/s, 각가속도2rad/s², dt0.01초, 차체·예약·공통 진입 가능 후보를 유지한다. 팀원의 속도1m/s·dt0.1초·각가속도 생략 모델 전체를 복사하지 않는다. 기존 GP-LCB·투영 PSO의 탐색 설정도 고정해서 규칙 효과와 섞지 않는다. 팀원 저장소의 수치를 직접 재현한 실험이라고 부르지 않는다.

기존 물리 엔진 파일은 변경하지 않고, 그 고정 버전에서 선택 부분만 확장한 별도 모듈을 사용한다. 보호 off의 모든 기존 출력 일치, 0초 보호의 FCFS 궤적 일치, 보호 대상이어도 진입 불가능하면 제외하는 검사를 포함한다. 유한한 정규화 점수에서는 원본의 1,000,000+대기시간과 같은 우선순위를 명시적인 정렬로 구현한다. 지역 대기는 integer tick 차이와 동등하게 계산한다. 임계값은 대기 상한 보장이 아니다.

## 지표와 분석

주지표 완료시간과 함께 차량별 누적 구역 진입 대기의 평균·p95·최대, 일반 통로를 포함한 전체 정지 대기, 출발 지연, 완료율을 기록한다. 다중 교차로의 누적 진입 대기는 여러 구역의 합이고, 보호 임계값은 각 지역 대기에 적용한다. 두 개념을 혼동하지 않는다.

동일 가중치 규칙 적용, 규칙 포함 재학습, 규칙을 고정한 재학습 효과를 각각 짝 비교한다. 48개 시나리오를 단위로 5,000회 부트스트랩 구간을 산출하되 탐색적·미보정 구간이라고 표시한다. 한 시드의 예비 결과로 확증적 유의성을 주장하지 않는다. 최대 대기만 줄고 완료시간이 늘면 상충관계로 보고한다.

## 계산 재사용과 검증

가중치·보호 조건·시나리오가 같은 결과를 재사용하고 각 방법의 예산에는 동일하게 포함한다. 추가로 완료된 무보호 궤적에서 모든 차량의 누적 진입 대기가 T보다 작다면 어느 지역 대기도 T에 도달할 수 없어 보호 T는 선택을 바꾸지 못한다. 이 경우에만 임계값 미도달을 증명한 결과를 재사용한다. 경계 여유 1e-8초를 두며 미완료 궤적에는 적용하지 않는다. 임계값 보호 상태 재실행과 일치하는지 고정 난수로 최대 24개 재사용 사례를 직접 검증한다.

원자적·에피소드별 체크포인트, 소스/자료/벡터 해시, 재사용 출처, 직접 실행과 논리적 평가 횟수를 구분해 저장한다. 실패는 삭제하지 않으며 목적함수는 미완료 수×1201+평균 제한 완료시간이다. 사용자 저장소에만 저장한다.
