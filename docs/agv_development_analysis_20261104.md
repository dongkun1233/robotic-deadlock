이 문서는 개발 자료의 탐색적 분석이다. 최종 독립 테스트는 생성·실행하지 않았다.

## 분석 단위

레이아웃마다 12개 조건 × 4개 시나리오 = 48개다. 각 시나리오에서 최적화 시드 5개의 결과를 먼저 평균하고 정책 간 차이를 계산했다. 240행을 독립 표본 240개로 취급하지 않았다. 12개 조건 내부에서 각각 4개를 복원추출하는 20,000회 부트스트랩을 사용했다(난수 시드 20261104). 아래 구간은 고정된 5개 학습 정책에 조건부인, 다중 비교 보정 전 탐색적 95% 구간이다. 새로운 학습 데이터나 새 최적화 시드의 불확실성을 포함하지 않는다.

## 해석

- single: BO/PSO는 무작위 탐색보다 평균 완료시간이 짧다. 초기 최선 후보와의 비교 구간은 두 방법 모두 0을 포함하므로 추가 탐색 효과를 확정하지 않는다.
- double: BO/PSO가 무작위 탐색보다 낫다는 근거는 약하다.
- multi: BO/PSO는 feasible-first FCFS보다 평균 완료시간이 길지만 해당 차이 구간은 0을 포함한다. 확정적인 열등성 주장도 피한다.
- 개발 결과를 보고 유리한 레이아웃이나 시드만 골라 최종 성능으로 보고하지 않는다.
- BO는 세 레이아웃 모두 54~72회 사이 평균 학습 목적함수 개선이 작다(최대 약 0.0022초). 이것은 전역 최적 수렴이나 충분한 예산의 증명이 아니다.

## FCFS 동작 점검

보존된 이전 코드 rware/agv_multicross_policy_simulation.py는 queue[0]을 고르고 막히면 break한다. 현재 rware/agv_timed_simulation.py의 strict_fcfs는 같은 선두 대기 규칙을 구현한다. 각 레이아웃의 첫 번째·마지막 개발 시나리오에서 두 FCFS를 실행한 총 12개 에피소드에서 선택 규칙, 안전 검사, 저장 makespan과의 정확한 일치를 확인했다. strict_fcfs는 뒤 후보 추월 진입 0회였고 feasible-first는 실제 추월을 보였다. 물리 모델·큐 구성·경로 등 원래 종설의 전체 구현과 동등하다는 의미는 아니다. 원래 종설 커밋이 식별되기 전에는 Strict FCFS를 ‘원래 종설 완전 재현’이라고 표기하지 않는다.

## 최종 테스트 계획 초안 — 실행 보류

모든 가중치를 현재 학습 결과로 고정한다. 5개 시드를 유지하고 개발에서 가장 좋은 시드를 사후 선택하지 않는다. 레이아웃당 19개 정책을 모두 평가한다. 15개 주 비교는 3레이아웃 × (basic/BO/PSO 대 feasible-first FCFS 3개 + BO/PSO 대 basic 2개)이며 최종 Holm 보정을 적용하는 계획이다. Strict FCFS·초기 최선·고정 가중치는 별도 보조 비교로 보고하고 확증 검정에 사용한다면 그 검정군도 사전에 확정한다.

최종 시나리오는 학습·개발·이전 물리 모델 자료와 미션 해시 중복을 검사한다. 개발과 같은 12개 조건 비중을 유지한다. 최종 결과 확인 후 가중치·정책·표본 수를 유리하게 변경하지 않는다. 미완료 실행도 제거하지 않고 고정된 패널티 목적함수와 완료율을 함께 보고한다.

### 표본 수 민감도

계획 효과는 각 레이아웃 개발 FCFS 평균의 백분율 포인트다. 이는 5개 고정 정책 평균의 시나리오 불확실성에 대한 정규근사 계획이며 검정력 보장이 아니다. 계획 표준편차는 쌍체 표준편차, 조건 내 합동 표준편차, 부트스트랩 표준편차 90백분위 중 최대값이다. 15개 양측 비교 Bonferroni 기준과 목표 검정력 80%, 레이아웃당 최소 96개 및 12의 배수 조건을 사용했다. Strict 비교는 이 15개 표본 수 계산에 포함하지 않았다.

표본 수 초안과 최종 테스트 실행은 아직 승인·확정되지 않았다. 이 분석 파일에는 시나리오별 원자료를 포함하지 않았다.
