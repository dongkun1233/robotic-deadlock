# 물리 시간 모델 예비 학습 결과 (2026-11-02)

최종 검증 결과가 아니라 본 실험 설계를 위한 예비 결과다. 최종 테스트는 생성·실행하지 않았다.

## 수행 범위

- 단일·이중·다중 교차로별 학습 12개, 개발 24개 시나리오: 총 학습 36개·개발 72개.
- AGV 12/24대 × 출발 창 0/15초 × 균등/진입 편중/출구 편중의 12개 조건.
- 방법별 18회 평가 × 탐색 시드 3개 × 레이아웃 3개 = 486회 목적함수 평가.
- FCFS·고정 4변수 기준·엄격 FCFS와 비교. 엄격 FCFS는 진입 규칙 비교로 분리.
- 공통 초기 후보 6개: FCFS, 기존 고정 가중치의 4변수 투영, 새 무작위 후보 4개.
- 같은 관측 재사용은 방법별 예산에 모두 포함. 기록된 완결 시뮬레이션 5,328개, 모두 완료.
- 저장 누락 3행을 재실행하여 복구했다. 원래 시도의 시간 기록은 복구되지 않아 CPU 합계에 포함되지 않는다. 중간 체크포인트는 완성 캐시와 같은 접두 기록임을 확인하고 중복 집계하지 않았다.

## 개발 시나리오 평균 전체 완료 시간 (초)

레이아웃당 서로 다른 시나리오 24개. 학습 방법은 탐색 시드 3회의 평균이다. 반복 시드는 독립 시나리오 수에 더하지 않았다.

| 레이아웃 | FCFS | 고정 4변수 기준 | 무작위 탐색 | BO | PSO |
|---|---:|---:|---:|---:|---:|
| 단일 | 140.16 | 141.27 | 138.98 | 136.76 | 138.03 |
| 이중 | 140.51 | 141.34 | 139.46 | 140.05 | 139.81 |
| 다중 | 137.08 | 138.12 | 136.82 | 138.31 | 138.19 |

단일에서는 BO의 평균이 가장 낮고, 이중·다중에서는 무작위 탐색의 평균이 가장 낮다. BO·PSO가 모든 레이아웃에서 우수하다는 결론은 성립하지 않는다. 예비 학습은 12개 시나리오·18회 평가뿐이며 PSO는 초기화 뒤 두 번의 세대 갱신만 수행했다. 수렴 또는 알고리즘 우열의 증거로 해석할 수 없다.

## 실험 수 추정

의미 있는 차이를 FCFS 평균 완료 시간의 1%로 정하고, 검정력 목표 80%, 사전 지정 비교 15개의 보수적 보정을 적용한 대략적 계산이다. 레이아웃별 다섯 비교 중 최대 필요 수를 취했다. 표본 표준편차·조건 내 표준편차·부트스트랩 표준편차 90백분위 중 최대를 사용하고 12의 배수로 올렸다.

| 레이아웃 | 잠정 최종 시나리오 수 |
|---|---:|
| 단일 | 372 |
| 이중 | 216 |
| 다중 | 1,248 |

레이아웃당 개발 표본이 24개뿐이라 필요 수 추정도 불안정하다. 아직 확정 수가 아니며 새 학습 뒤 개발 자료로 재추산하고 최종 테스트를 잠근다. Holm 보정과 동일 시나리오의 짝 비교를 적용하며, 탐색 시드 변동성은 별도로 제시한다. 0.5%·2% 목표의 민감도는 sample_size_sensitivity.csv에 있다.

## 다음 단계

1. 레이아웃별 학습 시나리오를 48개로 늘리고, 탐색 횟수 72회·탐색 시드 최소 5회의 후보 설계를 준비한다. 탐색 곡선으로 충분성을 추가 확인한다.
2. 초기 후보는 새 물리 모델의 학습 자료만으로 구성하고 모든 탐색 방법에 동일하게 제공한다. 개발 점수가 좋은 후보만 골라 우위를 만드는 방식은 사용하지 않는다.
3. 개발 자료에서 조건별 편차·탐색 시드 변동·수치 시간 간격 민감도를 다시 점검한다.
4. 비교·목표 차이·표본 수를 확정한 뒤 새 최종 테스트를 생성한다.
5. 변수 ablation은 제거 모델마다 같은 예산으로 재학습하고, 진입 규칙 효과는 별도 비교한다.

## 계산 비용과 한계

기록된 시뮬레이션의 평균 CPU 시간은 약 0.496초다. 위 잠정 본 학습은 평가 예산 기준 155,520개 에피소드로 약 21.4 CPU 시간이다. 8코어가 고르게 활용되면 단순 환산 약 2.7시간이지만, 탐색기 비용·실행 편차·추가 검증은 별도다. 캐시로 실제 비용은 줄 수 있다. 4개 제거 모델을 추가하면 예산이 크게 증가하므로 먼저 기본 비교를 검증한다.

현실성은 명시한 가정 범위다: 일정 직진 속도·제자리 회전·차체만·고정 경로·보수적 예약. 실제 창고의 가감속, 적재물, 동적 장애물까지 검증한 모델은 아니다. 안전 assertion 통과가 실제 AGV 안전 인증을 의미하지 않는다.
