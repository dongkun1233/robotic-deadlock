# 다중 교차로 AGV 연구: 관련 문헌과 변경 후보

검토일: 2026-10-31. 출판사, 저자 공개본, 소속 대학 저장소를 우선 검색했다. 검색 범위는 AGV 지역 교통 제어, 다속성 우선순위, 교차로 예약, 유한 통로 혼잡, 공정성, 구역 이산화이다. 모든 관련 논문을 망라한 체계적 문헌고찰은 아니다. 아래 13편은 확인 가능한 내용 범위에서 검토했고, 밀접한 추가 1편은 서지만 확인했다. 원문 전체를 확보하지 못한 문헌을 정독했다고 표현하지 않는다. 검색 결과의 요약과 논문의 검증된 성능을 구분한다.

## 코드에서 확인한 점과 제안의 우선순위

현재 네 변수는 waiting, maneuver, exit_competition, path_conflict다. exit_competition은 대기 후보 중 같은 출구 셀을 쓰는 다른 후보 수이고 실제 출구 통로의 차량 수가 아니다. path_conflict도 대기 후보끼리의 대칭적인 구역 경로 겹침 개수다. 두 후보만 있으면 이 두 개수는 각각 양쪽에 동일하므로 둘을 구분하는 데 기여하지 못한다. 세 후보 이상에서는 달라질 수 있다. 값의 차이가 존재한다는 사실과 성능 개선은 다른 주장이다.

### 1. 실행 가능한 후보 중 순위 선택: 이번 구현

구역 내부 경로와 첫 출구 셀의 현재 점유·예약 여부를 먼저 확인한다. 가능한 후보가 있으면 FCFS도 가중치 정책도 그 집합에서 선택한다. 기존 안전 예약 범위와 차량 이동은 유지한다. 막힌 최고순위 때문에 가능한 다른 후보까지 멈추는 소프트웨어 수준의 head-of-line blocking을 줄이는 변경이다. 문헌 6과 문제 구조가 연결되지만, 그 논문의 제어 법칙을 구현한 것은 아니다. 전역 교착 방지 정리는 없다.

v1(strict_first)과 v2(feasible_first)를 별도 모듈로 보존했다. 변수 값·정규화는 기존처럼 전체 대기 후보로 계산하고, 선택 자격만 필터링한다. 새 FCFS는 정확히 '진입 가능한 후보 중 도착순'이며 기존의 엄격한 첫 후보 우선 규칙과 구별해 표기한다. 두 정책 모두 동일한 안전 필터를 사용해야 비교가 공정하다.

### 2. 하류 통로 혼잡도: 가장 먼저 검토할 추가 변수

각 후보의 구역 출구부터 다음 교차로 대기점 또는 최종 출구까지 고정된 유향 통로를 정의한다. 현재 활성 차량이 점유하거나 예약한 셀의 합집합 크기를 그 통로 셀 수로 나눈 점유율을 사용한다. 중복 점유·예약을 이중 계산하지 않는다. 미출발 차량이나 미래 실현 교통량은 관측값에 넣지 않는다.

이는 같은 출구를 원하는 '현재 후보 수'와 다르며 후보가 두 대뿐이어도 서로 다른 하류 통로의 혼잡도를 구분할 수 있다. 문헌 1, 5, 6이 동기를 제공한다. 첫 실험은 전체 4변수에 이 변수 하나를 추가하고, 기존 exit_competition을 이것으로 교체하는 실험을 별도로 한다. 성능 향상은 아직 검증하지 않았다.

### 3. 접근로 대기열과 하류 혼잡의 차이: 2번 다음

접근 통로에서 실제 진입 대기점 뒤에 줄 선 활성 차량 수를 센다. 대기점에 서 있는 선두 후보만 세면 예전 approach_queue처럼 항상 같은 값이 될 수 있으므로, 통로 구간과 방향을 명시해야 한다. 관측 가능한 접근/하류 점유율의 차이는 pressure-inspired 변수로 시험할 수 있다. 단순 점유율 차이는 문헌 6의 비선형 정규화 압력과 같지 않으며 max-pressure 최적성 증명을 주장할 수 없다.

2번과 3번은 유사 정보를 포함할 수 있다. 둘을 처음부터 동시에 추가하지 않고, 후보 간 값 차이와 조건부 추가 성능을 확인한다. 두 대 후보에서 차별성이 늘었다고 성능 향상으로 결론내리지 않는다.

### 4. 장기 대기 보호: 공정성을 위한 별도 규칙

진입 가능한 차량 중 대기가 사전에 정한 임계값을 넘은 차량이 있으면 그중 가장 오래 기다린 차량을 먼저 통과시키고, 그렇지 않으면 기존 점수를 사용한다. 임계값은 학습/검증에서 정하고 최종 테스트에서는 고정한다. 배치·시간 우선권 문헌 4, 12, 13이 동기다. 불가능한 차량에 강제로 진입 허가를 주지 않는다. 아직 공정성 보장이나 효율 개선이 증명된 규칙은 아니다.

현재 가중치 탐색은 음수 waiting도 허용하므로 오래 기다린 차량의 점수를 낮출 수 있다. waiting 가중치 부호 제한과 임계 대기 규칙은 서로 다른 실험이다. 총 완료시간만 최적화하면 일부 차량의 대기 악화를 놓칠 수 있어 차량별 평균·95백분위·최대 지연을 함께 평가해야 한다. 유한 작업 묶음 실험만으로 지속 유입 상황의 기아 방지를 주장하지 않는다.

### 5. 호환 가능한 차량 쌍 선택: 두 번째 단계의 규칙 실험

현재는 가장 높은 점수 한 대를 고른 다음 두 번째를 고른다. 교차로 용량이 2이고 선두 후보가 최대 4대라면 가능한 단일 후보와 쌍을 전부 열거해 비교할 수 있다. 기존 점유·예약과 충돌하지 않고 쌍 사이 예약 셀도 겹치지 않는 집합만 허용한다. 집합 크기 우선, 이후 점수 합 등의 목적을 미리 정한다. 문헌 8과 연결되는 작은 조합 선택 실험이다. 최대 두 대 동시 진입이 항상 전체 완료시간을 최소화하지는 않는다.

이는 path_conflict 숫자를 다른 숫자로 바꾸는 것보다 '충돌 정보를 실제 선택에 어떻게 쓰는가'를 직접 검증한다. 정확한 시공간 예약이나 maximum-clique 논문 전체의 재현은 아니다. 첫 변경과 동시에 적용하지 않는다.

### Maneuver 변경은 우선순위가 낮다

좌·직·우에 붙인 0/0.5/1 대신 실제 로컬 구역 경로의 셀 수를 사용할 수 있다. 그러나 현재 고정 격자에서 두 값이 거의 같은 정보를 나타낼 수 있어 먼저 일대일 대응 여부를 확인해야 한다. 회전 시간이 없는 모델에 임의의 회전 비용을 넣어 물리적으로 더 현실적이라고 말하지 않는다. 남은 총 경로 길이도 후보이지만, 짧은 작업 우선이 평균 완료시간과 전체 makespan을 동시에 개선한다는 보장은 없다.

## 지금은 채택하지 않을 변경

배터리 잔량, 충전, 작업 납기, 적재 우선순위는 현재 모델에 실제 제약이 없다. 변수를 인위적으로 만들어 추가할 근거가 부족하다. 강화학습, 재경로 계획, 연속 운동/회전, 시공간 예약 전체 교체는 연구 범위를 크게 바꾸므로 현재 네 변수 검증 전에 도입하지 않는다. 동적 가중치는 관련 문헌이 있지만 고정 가중치와 변수의 효용부터 확인해야 한다.

## 실험을 나누는 방법

1. 같은 시나리오와 같은 고정 가중치에서 v1과 v2 비교: 진입 규칙 변경 효과.
2. 각 규칙에서 동일 예산으로 재탐색한 결과 비교: 규칙에 맞춘 정책 학습의 효과. FCFS도 각각의 규칙을 적용한다.
3. 선택한 규칙을 고정하고 full과 변수 하나씩 제거한 모델을 같은 예산으로 재탐색: 나머지 변수가 보상할 수 있을 때 해당 변수의 추가 효용. 고정 가중치 제거는 별도 진단이다.
4. full 대 추가/교체 변수 비교를 학습·검증에서 수행한다. 한 번에 하나씩 변경하고 임계값·특징 정의·선택 기준을 기록한다.
5. 최종 모델과 분석을 고정한 뒤 독립 테스트를 한 번 사용한다. 본 검토 이후 새 아이디어를 검증 결과로 반복 고르면 그 검증 세트는 개발 자료로 취급한다.

비교 단위는 고유 시나리오다. 최적화 시드별 반복을 서로 다른 교통 시나리오로 세지 않는다. 짝지은 차이, 완료율, 평균/최대 대기, 출발 지연, 실시간 계산 비용을 보고한다. 다중 변수 검정을 할 때 보정하거나 탐색 분석임을 명시한다. 관측된 작은 차이나 신뢰구간의 0 포함은 동등성의 증명이 아니다.

연구 기여의 후보는 기존 아이디어 자체가 아니라, 연결 교차로에서 안전한 동일 진입 조건 아래 변수의 조건별 유효성과 불필요성을 재현 가능하게 검증하는 데 있다. 신규성이나 논문 채택 가능성은 아직 확정할 수 없다.
